Solvex Audio 1.0.0-beta3.1: licence fixes and your data carried over

4 November 2026 · Windows, macOS and Linux · Patch for 1.0.0-beta3

A small fix release. Home and Pro licence keys now unlock the edition you bought, and your settings, drivers and projects from older versions come with you. No new features.

Download 1.0.0-beta3.1 What was new in 1.0.0-beta3

Already on 1.0.0-beta3?

The update check in 1.0.0-beta3 can't see this patch, so please download it from this site. Install it first, then go to File → Activate License… and enter your key again.

Licences

  • Fixed: Home and Pro licences unlocked only Basic. The app didn't recognise the names of the paid plans, so every paid key activated as Basic. Plans are now recognised reliably, and if the app ever can't tell which plan a key is for, it says so instead of quietly giving you Basic.
  • Fixed: trying again used up your activations. Each new attempt counted as a new computer until the key reached its activation limit. Entering the same key again on the same computer now re-checks the activation you already have.
  • Fixed automatically: if your licence was stored as Basic by mistake, it's corrected the next time the app checks your licence online.
  • Licence checks are stricter about which keys they accept.

Your data carries over

  • Settings no longer reset after updating. Theme, units, language and update preferences from older versions are brought over automatically. Choices you already made in 1.0.0-beta3 are kept.
  • One data folder. Drivers, projects, settings and licence now all live in ~/.solvexaudio. Your drivers and projects from older versions (the ~/.nordsonic folder) are copied in on the first start, without duplicates. The old folders are left untouched.
  • A trial started in an older version keeps its original start date.

Updates and other fixes

  • The update check understands patch versions such as 1.0.0-beta3.1, so future patches are offered to you automatically.
  • The About box shows the company name correctly (NordBass).

The Basic edition is free forever. Home and Pro can be tested free during the beta.
